# Application

The application layer defines user actions, their data contracts, validation,
and infrastructure-independent behavior. It depends only on the domain layer.

Adaptive tutoring is represented by explicit start, continue, retrieve, delete,
and document-brief use cases. Study Mission policy, capability execution,
milestone/material handling, learner assessment/remediation, interaction
handling, persistence, verification, and result construction are framework-free
services. LangGraph only sequences those operations through thin adapter nodes.

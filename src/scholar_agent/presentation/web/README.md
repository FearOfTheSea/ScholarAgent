# Streamlit adapter

The Streamlit adapter exposes the local PDF Library, **Study Mission**, and
**Quick Ask** workflows. It translates presentation input into application
requests and renders typed results without business logic.

The Study Mission workspace displays the cached document map, concept
prerequisites, mastery, persistent conversation, and expandable page/chunk
evidence while delegating all behavior to application use cases.

The Today page provides an explicit learner-profile selector and plain-language
review cards with source document, confidence and uncertainty learning
signals, reason, expected time, and Start review. Profile creation, redacted
export/import, and deletion are available under profile management.
